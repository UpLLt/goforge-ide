# Stable LSP intention descriptions

This is a metadata-only integration patch for the open-source LSP4IJ **0.21.0** dependency, under its included [EPL-2.0 license](LICENSE). Upstream source: <https://github.com/redhat-developer/lsp4ij/tree/0.21.0>. The upstream plugin's `LSPLazyCodeActionIntentionAction` initially returns a localized family name, while its description resources have English directory names. IntelliJ 252 consequently searches for a nonexistent localized directory when indexing intentions for Find Action.

The patch gives each of the 20 dynamic intention registrations an explicit, stable `<descriptionDirectoryName>Empty</descriptionDirectoryName>`, referring to the description already shipped in the dependency. It changes no Java class, action availability, quick fix, request, license or subscription behavior. `stable-intention-description.patch` records the complete XML diff; all other archive-entry contents remain byte-identical.

Run `python3 scripts/patch-lsp4ij-metadata.py --plugin-dir <owned-copy-of-lsp4ij>` after copying dependencies into a GoForge sandbox or distribution. The Gradle sandbox preparation hook performs this automatically. The standalone application assembler must invoke the same script on its dependency copy. The script refuses unknown input or output hashes, unexpected versions, any action count other than 20, missing description resources, duplicate entries, signed JARs, hard links and paths outside this project's build/distribution directories. Reruns validate the pinned patched hash and are idempotent. Source and patched SHA256 values are in the script, and each destination receives a provenance receipt.

The original Gradle download cache and user plugin installations are never modified. A GoForge plugin ZIP installed separately alongside an unpatched upstream LSP4IJ dependency does **not** include this dependency fix. A dependency upgrade requires reviewing and repinning this patch; it must not silently apply to another version.
