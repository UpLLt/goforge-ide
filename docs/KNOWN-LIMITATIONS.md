# Known limitations / 已知差距

GoForge is an internal development build. Complete GoLand feature parity, a complete original-product runtime baseline, and a meaningful overall completion percentage have **not** been established. Counts of tests or integrated libraries are not a completion percentage.

GoForge 当前是内部开发构建。**完整 GoLand 对齐尚未证明**；也未建立完整原产品运行基线或可信的总体完成百分比。测试数量和依赖数量不能换算成功能完成度。

The newest development source adds imports-on-save and one selected top-level Benchmark Run. **Their integrated regression passed in Full 10 (723 tests); native UI and Windows acceptance remain pending. These additions are included in the newly assembled 2406 Mac package; Windows Run 8 used the older 318d baseline and excluded them.** See the scoped [imports workflow](USAGE.md#organize-imports-on-save--保存时整理导入) and [benchmark workflow](USAGE.md#run-one-benchmark--运行单个基准测试).

最新开发源码新增保存时整理导入、运行一个选定的顶层 Benchmark。**这两项的整合回归已在 Full 10（723 项测试）通过，原生界面及 Windows 验收仍待完成；新组装的 2406 Mac 包已包含这两项；Windows 第 8 次使用旧 318d 基线，不包含这两项。** 操作与边界见[保存时整理导入](USAGE.md#organize-imports-on-save--保存时整理导入)及[运行单个基准测试](USAGE.md#run-one-benchmark--运行单个基准测试)。
